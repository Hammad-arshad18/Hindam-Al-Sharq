# Hindam Al-Sharq

Read `CLAUDE.md` before changing the site. The rules there apply here too.

## Images

Photographs are WebP.

- Home photos: `assets/img/g-*.webp`
- Line-page photos: `assets/img/l-<key>-a.webp` through `l-<key>-g.webp` (`a` hero, `b` intro, `c` wide band, `d`–`g` captioned strip)
- Logos: `logo-mark.webp`, `logo-mark-360.webp`
- Tab icon: `favicon.webp`
- Apple home-screen icon stays `favicon.png`

Point `src`, CSS `url()`, and preloads at `.webp`. Do not add `.jpg` photographs. `.htaccess` caches images for 7 days.
